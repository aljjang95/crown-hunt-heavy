# CROWN HUNT

**Five Minutes to Ascend.**

Crown Hunt is a single-run browser action game built around one identity: **the broken crown chooses a new owner every five minutes**.

## Core loop

**HUNT → CLAIM → ASCEND → CROWN**

- Move with WASD / arrow keys or the mobile joystick.
- Attacks automatically target the nearest enemy.
- Defeated hunters drop **Royal Shards**.
- Each ascent offers one of three royal oaths.
- A stronger **Pretender** enters at 01:00, 02:00, 03:00, and 04:00.
- Survive to 05:00 to reach **Coronation**.

## v2 identity

- Obsidian court, tarnished crown gold, warm ivory, coronation red.
- Fractured-crown / broken-halo visual motif.
- The 05:00 coronation clock is the primary HUD promise.
- Distinct Pretender event treatment and elite silhouette.
- Upgrade families are framed as Royal Decrees, Oaths, Shards, and Crownless techniques.
- Victory and defeat now have different narrative endings.
- Responsive desktop and mobile controls remain in the single-file browser build.

## Run

Open `index.html` in a browser or serve the repository with any static HTTP server.
